# AgentLens

Agent discovery and verification infrastructure for AI agents on BNB Smart Chain.

## Day 1 MVP

The first milestone is deliberately small:

**Discover → Parse → Probe → Store**

AgentLens will discover ERC-8004 agents on BNB Smart Chain, resolve their registration metadata, identify declared service endpoints, safely check endpoint health, and store the results for later marketplace features.
